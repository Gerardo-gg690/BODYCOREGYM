BODYCORE GYM — Promociones personalizadas

En Registrar cliente, elige «Promoción personalizada». Escribe el nombre, la duración en días y el precio pagado. El vencimiento se calcula desde la fecha de inicio. El nombre y duración se guardan con el cliente, y se pueden editar.

Conserva tu firebase-config.js actual. Sube los archivos descomprimidos a la raíz del repositorio GitHub.

Nota: Esta versión modifica el alta y edición de clientes; las renovaciones mantienen las opciones existentes. Prueba primero con un cliente de ejemplo.
